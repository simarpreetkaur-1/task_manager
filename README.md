# Task Manager 

A simple and aesthetic To-Do List Android application developed using Java and XML in Android Studio.

# Features

- Add new tasks.
- View all added tasks.
- Mark tasks as completed.
- Delete tasks.
- Categorize tasks into Study, Personal, Work and Other.
- Assign High, Medium and Low priorities.
- Automatically sort tasks according to priority (High to Low).
- Track completed tasks using a progress indicator.

## Tech Stack

- Java
- XML
- Android Studio

## UI Design

The application features a soft pastel colour palette.
